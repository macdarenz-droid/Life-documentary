# T-005 · P7 Question engine

Text for T-005a–b. Published 2026-09-26; this file does not change after publication. Fix lists are written in `tasks/TASKS.md` under the task.

## Preamble

**Goal of P7.** Every day the app asks exactly one specific, warm question, chosen by a pure and deterministic engine from a tagged bank of at least 120 templates, never repeating a template within 60 days, following open storylines on about two days a week, and never shaming a quiet stretch. The engine is pure code in `packages/story`; wiring it to the store and the Today screen happens in P8/P9, not here.

**Read first:** `CLAUDE.md`, `docs/VISION.md` §2 (principles 1, 3, 5), `docs/architecture/ARCHITECTURE.md` §4 "Question engine" and §6, DECISIONS D1, D2, D5, D21.

**Versions.** No new dependencies. `packages/story` keeps depending only on `@life/contracts`; `packages/contracts` only on `zod`.

**Owners table.**
| Path | Task |
|---|---|
| `packages/contracts/src/question.ts` and its test | T-005a |
| `packages/story/src/dates.ts` and its test | T-005a |
| `packages/story/src/words/questions.ts` and its test | T-005a |
| `packages/story/src/questionEngine/**` and its tests | T-005b |

**Rules for both tasks.**
- Pure: no clock (`Date.now()`, `new Date()` without arguments), no `Math.random`, no I/O. Dates are `LocalDate` strings (`YYYY-MM-DD`); date arithmetic goes through `packages/story/src/dates.ts`, which may build `Date` objects only with `Date.UTC(...)`.
- Determinism comes from a string `seed` passed in (the caller will pass the documentary id), hashed together with the date. Implement a small pure hash (FNV-1a 32-bit) inside `packages/story`; no dependency.
- Names of people, places and storylines are typed by the user; the engine only fills them into slots. No biometrics, no inference about the person (CLAUDE.md rule 7).
- Words: plain, warm, specific, documentary tone; no exclamation marks; none of `bannedWords`; never guilt ("you missed", "you forgot", "again", "finally").

**Out of scope.** Storing questions (P3 repositories, P8 wiring), notifications (P9), the Today screen (P5), model-personalised wording (P7.2), storyline creation (P8).

## T-005a · Question contracts, dates and the template bank · needs T-001a

**Goal.** The shapes the engine uses are contracts, the date helpers exist and are tested, and a bank of at least 140 tagged templates lives in `packages/story/src/words/questions.ts` and passes its content rules.

**Do.**
1. `packages/contracts/src/question.ts`, exported from the package index:
   ```ts
   QuestionTag = z.enum(['after_quiet_days', 'anniversary', 'open_storyline', 'person_seen',
                         'place_first_time', 'weekday', 'weekend', 'season', 'general'])
   QuestionTemplate = z.object({
     id: z.string().regex(/^q\d{3}$/),
     tags: z.array(QuestionTag).min(1),
     text: z.string().min(12).max(120),          // may contain one slot: {storyline}, {person} or {place}
   })
   QuestionPick = z.object({
     templateId: z.string().regex(/^q\d{3}$/),
     reason: QuestionTag,                         // the rule that chose it
     text: z.string().min(12).max(200),           // slots filled, no '{' or '}' left
     storylineId: Uuid.optional(),
   })
   ```
   Export the inferred types with the same names.
2. `packages/story/src/dates.ts`, exported from the package index: `addDays(date, n)`, `daysBetween(a, b)` (b − a in whole days, may be negative), `dayOfWeek(date)` (0 = Sunday … 6 = Saturday), `isWeekend(date)` (Saturday or Sunday), `oneYearBefore(date)` (same month and day in the previous year; 29 February maps to 28 February). All take and return `LocalDate` strings (or numbers) and never read the clock.
3. `packages/story/src/words/questions.ts`: `export const questionTemplates: readonly QuestionTemplate[]`, exported from the package index. At least these counts per tag (a template may carry several tags; a template counts once per tag it carries):
   | Tag | At least | Slot | Example of the tone |

   | `open_storyline` | 20 | `{storyline}` required | "Where are things with {storyline} this week?" |
   | `after_quiet_days` | 12 | none | "It has been a quiet few days. What is one small thing from today?" |
   | `anniversary` | 8 | none | "A year ago today you recorded a moment. What is different about today?" |
   | `person_seen` | 16 | `{person}` required | "You spent time with {person} yesterday. What did you talk about?" |
   | `place_first_time` | 10 | `{place}` required | "Yesterday you were at {place}. What was it like the first time?" |
   | `weekday` | 20 | none | "What was the best ten minutes of your workday?" |
   | `weekend` | 16 | none | "What did this weekend morning sound like?" |
   | `season` | 8 | none, hemisphere-neutral | "The light changes this time of year. What did you notice today?" |
   | `general` | 30 | none | "What made you laugh today?" |
   Total at least 140 distinct templates, ids `q001`… in order with no gaps. Every text is one question, ends with "?", can be answered out loud in ten seconds, addresses the person as "you", and uses at most one slot. Templates tagged with a slot tag carry only that tag.

## T-005b · The engine and a simulated year · needs T-005a

**Goal.** `pickQuestion(context)` returns exactly one `QuestionPick` for a day, deterministically, following the rules below, and a simulated year proves the rules hold.

**Do.**
1. `packages/story/src/questionEngine/types.ts`:
   ```ts
   type QuestionContext = {
     today: LocalDate;
     seed: string;                                   // documentary id; any non-empty string
     templates: readonly QuestionTemplate[];         // normally questionTemplates
     openStorylines: readonly { id: Uuid; title: string; openedOn: LocalDate }[];
     recentDays: readonly {                          // the 7 days before today (any order; missing day = no moments)
       date: LocalDate; momentCount: number; placeNames: readonly string[]; castNames: readonly string[];
     }[];
     placesBefore: readonly string[];                // distinct place names seen before the 7-day window
     momentsOneYearAgo: number;                      // moments on oneYearBefore(today)
     history: readonly { askedOn: LocalDate; templateId: string; storylineId?: Uuid }[];  // at least the last 60 days
   };
   ```
2. `packages/story/src/questionEngine/pickQuestion.ts`, exported from the package index: the first rule that applies and has an eligible template wins.
   1. `after_quiet_days`: the three days before today all have `momentCount` 0 (a day missing from `recentDays` counts as 0).
   2. `anniversary`: `momentsOneYearAgo > 0`.
   3. `open_storyline`: at least one open storyline; no storyline question in the previous 2 days; fewer than 2 storyline questions in the previous 6 days. The storyline is the open one whose most recent storyline question is oldest (never asked first); ties by `openedOn`, then `id`. Fill `{storyline}` with its title and set `storylineId`.
   4. `person_seen`: yesterday has a cast name; use the first name in yesterday's `castNames` sorted alphabetically (case-insensitive).
   5. `place_first_time`: yesterday has a place name not in `placesBefore` and not in any other day of `recentDays`; the first such name alphabetically.
   6. Otherwise the day pool: templates tagged `general`, `season`, and `weekend` on Saturday and Sunday or `weekday` on the other days.
   A template is eligible when its id is not in `history` within the 60 days before today (`daysBetween(askedOn, today) <= 60`). Among the eligible templates of the chosen rule, sorted by id, pick index `fnv1a(seed + ':' + today + ':' + reason) % count`. If a rule applies but has no eligible template, fall through to the next rule. If the day pool has no eligible template, take the day-pool template whose most recent ask is oldest (ties by id); this is the only case where a template repeats within 60 days.
3. The result is built with `QuestionPick.parse`. Slot values are trimmed; a filled text longer than 200 characters falls through to the next rule.
4. `packages/story/test/fixtures/simulatedYear.ts`: a pure generator for a synthetic year from 2027-01-01 to 2027-12-31 with: most days 1–3 moments; three quiet stretches (4, 6 and 10 days) starting at least 70 days apart; storyline "The new job" open 2027-02-01 → 2027-06-30 and "Training for the half marathon" open 2027-04-01 → 2027-10-15; cast names on about one day in five; about 25 new place names spread over the year; `momentsOneYearAgo > 0` on 12 dates at least 20 days apart that are not inside or right after a quiet stretch. The simulation feeds every pick back into `history`.

**Tests** (`packages/story/test/questionEngine.test.ts`), one behaviour each:
- Each rule on a hand-built context: quiet days → `after_quiet_days`; anniversary → `anniversary`; storyline eligible → `open_storyline` with `storylineId` and the title in the text; person → the alphabetically first name in the text; new place → that place; otherwise the weekday pool on a Monday and the weekend pool on a Saturday (check the chosen template's tags).
- Storyline choice: the least recently asked of two open storylines is chosen.
- A storyline asked yesterday blocks the storyline rule today; two storyline questions in the previous 6 days block it too.
- Fall-through: the storyline rule with every storyline template asked in the last 60 days falls through to the next rule.
- Exhaustion: with every day-pool template asked within 60 days, the pick is the one asked longest ago.
- Determinism: the same context gives the same pick; changing only `seed` changes at least one pick over the simulated year.
- Simulated year: 365 picks, each parses with `QuestionPick`; no template repeats within 60 days (the exhaustion path never happens); the day after each quiet stretch is `after_quiet_days`; each of the 12 anniversary dates is `anniversary`; in every 7-day window at most 2 `open_storyline` picks, and at least 1 in every 7-day window that lies fully inside a period with an open storyline and contains no quiet day; no text contains `{` or `}`.

**Acceptance.** Package tests, typecheck, lint, format, `pnpm boundaries` pass; `packages/story` imports only `@life/contracts` and `zod`; no clock or `Math.random` in `packages/story/src` (reviewer checks the diff); report the per-reason counts of the simulated year under Decisions.
