# T-003 · P2 Design system and motion

Text for T-003a–e. Published 2026-09-26; this file does not change after publication. Fix lists are written in `tasks/TASKS.md` under the task.

## Preamble

**Goal of P2.** The app and the rendered episodes share one set of tokens (colour, type, motion, haptics, texture) and a small kit of primitives and signature motion components, built to `docs/design/DESIGN.md`. The owner asked for premium, smooth, non-template design; P2 is where that is made real and checkable before any product screen exists.

**Read first:** `docs/design/DESIGN.md` (all of it), `CLAUDE.md`, `docs/architecture/ARCHITECTURE.md` §2 (`design-system/` row) and §7, DECISIONS D25, D29–D31.

**Versions.** Native modules only through `npx expo install <pkg>` in `apps/mobile` so they match Expo SDK 57 (DESIGN §5): `react-native-reanimated` (4.5.1), `react-native-worklets` (0.10.1), `react-native-gesture-handler` (~2.32.0), `@shopify/react-native-skia` (2.6.2), `expo-haptics`, `expo-image`, `expo-font`, `expo-splash-screen`, `@expo-google-fonts/instrument-serif`, `@expo-google-fonts/inter`. Render: `@remotion/google-fonts` or local font files, `@remotion/transitions`, `@remotion/noise` at exactly `4.0.529`. Report every installed version under Decisions.

**Rules for every P2 task.**
- Only transform and opacity animate. Springs from `motion.spring`, curves from `motion.ease`; no inline numbers for motion, colour, size or spacing anywhere outside `packages/design`.
- Every animated component takes its reduced-motion path from one hook, `useMotionPreference()` (T-003b), and has a test for that path.
- No damping ratio below 0.85; no animation on things that happen many times a day (DESIGN §1 rule 7).
- User-facing strings come from `packages/story/src/words`.

**Allowed test changes (P2 only).** T-003a replaces T-001a's `font.size` and `motion.durationMs` tokens; update `packages/design/test/contrast.test.ts` and `apps/mobile/src/features/today/TodayPlaceholder.test.tsx` only as far as the renamed tokens require, and list each change.

**Out of scope.** Premiere, Letterbox, Filmstrip, Tray detents, Record (built with their screens in P5, P10, P16); any product screen; paid fonts; icons and app art.

## T-003a · Tokens and words · needs T-001a

**Goal.** `packages/design` holds every token from DESIGN §2, the spring damping values are computed and pinned by tests, and `packages/story/src/words` owns user-facing strings with the banned-words rule tested.

**Do.**
1. `packages/design/src/color.ts`: the seven colour tokens from DESIGN §2. `ash` and `scrim` are expressed as `{ hex: '#F4F1EC', alpha: 0.6 }` and `{ hex: '#0A0A0C', from: 0, to: 0.85 }`, with a helper `rgba(hex, alpha)` returning `rgba(r, g, b, a)`. Semantic aliases: `background`, `surface`, `text`, `textSecondary` (ash), `accent`, `focus`.
2. `packages/design/src/type.ts`: families `display: 'InstrumentSerif_400Regular'`, `displayItalic: 'InstrumentSerif_400Regular_Italic'`, `text: 'Inter_400Regular'`, `textStrong: 'Inter_600SemiBold'` (the exact names exported by the `@expo-google-fonts` packages; check them). Variants (size, lineHeight, family, letterSpacing, textTransform?): `display64`, `display48`, `display34`, `question` (displayItalic 34), `body` (text 16/24), `bodyStrong` (textStrong 16/24), `label` (textStrong 12, uppercase, letterSpacing = 6% of size), `caption` (text 13/18), `timecode` (textStrong 13, `fontVariant: ['tabular-nums']`). No variant between 17 and 33 pt (DESIGN §1 rule 2).
3. `packages/design/src/motion.ts`: exactly the `spring`, `ease`, `duration`, `stagger`, `scale`, `texture`, `letterboxAspect` objects of DESIGN §2, except that each spatial spring's `damping` is produced by `dampingFromRatio(ratio, stiffness, mass)` = `ratio × 2 × √(stiffness × mass)` rounded to the nearest integer, from ratios `press 0.9`, `move 0.9`, `scene 0.9`, `effect 1.0`. Also `reducedMotion = { fadeMs: duration.micro }` and `haptics = { detent: 'selection', recordStart: 'impactLight', recordStop: 'impactLight' } as const`.
4. Keep `space` and `radius` from T-001a. Remove `font.size` and `motion.durationMs` (replaced by `type` and `motion`). `src/index.ts` exports `tokens = { color, type, motion, space, radius, haptics }` and each module by name.
5. `packages/story/src/words/index.ts`: `words` object with the strings the app has today (`today.placeholderTitle: 'Life Documentary'`, `today.placeholderLine: 'Your first question arrives soon.'`, `lab.title: 'Design lab'`, `lab.replay: 'Play again'`, `lab.reducedMotionOn: 'Reduced motion is on'`, `button.holdToAnswer: 'Hold to answer'`, `button.recording: 'Recording'`, `button.saved: 'Saved'`) and `bannedWords = ['streak', 'badge', 'level up', 'leaderboard', 'points', 'xp']`. Export from the package index.

**Tests.**
- `packages/design/test/motion.test.ts`: `dampingFromRatio(0.9, 1400, 1) === 67`, `(0.9, 700, 1) === 48`, `(0.9, 300, 1) === 31`, `(1, 1600, 1) === 80`; every spatial spring's damping ratio computed back from its values is ≥ 0.85; `spring.release.dampingRatio ≥ 0.85`; every `ease` entry has four numbers with x1 and x2 in [0, 1]; `stagger.list × stagger.listCap ≤ duration.ui`.
- `packages/design/test/type.test.ts`: no variant size in 17–33; `timecode` has tabular numbers; `label` is uppercase with letterSpacing 0.72.
- `packages/design/test/contrast.test.ts` (extended): `text` on `background` ≥ 7; `textSecondary` blended over `background` ≥ 4.5; `accent` on `background` ≥ 4.5; `focus` on `background` ≥ 3.
- `packages/story/test/words.test.ts`: walks every string in `words` (recursively) and fails if any contains a banned word (case-insensitive, word boundary) or an exclamation mark.

**Acceptance.** Package tests, typecheck, lint, boundaries pass; `packages/design` still has no dependencies; `packages/story` still imports only `@life/contracts` and `zod`; the mobile placeholder and render packages still typecheck after the token rename (update their imports only as the allowed test changes and a minimal typecheck fix require).

## T-003b · Fonts, primitives and the motion preference · needs T-003a, T-001c

**Goal.** The app loads the two typefaces before first paint and offers `Text`, `Button`, `Field` and `Surface` primitives plus `useMotionPreference()`, all reading only tokens.

**Do.**
1. `npx expo install` the libraries in the preamble that this task uses (Reanimated, worklets, Gesture Handler, haptics, expo-font, expo-splash-screen, both font packages). Configure Reanimated per its 4.x docs for SDK 57 (Babel plugin or the worklets plugin, whichever the docs require; name it under Decisions). Wrap the root in `GestureHandlerRootView`.
2. `app/_layout.tsx`: keep the splash screen until both fonts load (`useFonts`), then hide it; if loading fails, render with system fonts and `console.warn` once (never block the app).
3. `src/design-system/Text.tsx`: `<Text variant="display64" | … >` mapping to `tokens.type`; `accessibilityRole="header"` default for display variants; respects the OS font scale with `maxFontSizeMultiplier` 1.4 for display and 2 for body.
4. `src/design-system/Button.tsx`: variants `primary` (amber background, `theatreBlack` text) and `quiet` (transparent, `screenWhite` text, `ash` border 1 px). Press feedback: scale to `motion.scale.press` on `spring.press` on press-in and back on press-out, opacity only when reduced motion. Optional `haptic` prop (`'impactLight' | 'selection'`) fired on press-in via expo-haptics. `accessibilityRole="button"`, `accessibilityState.disabled`. Minimum touch target 44 × 44. Label text through `Text` `bodyStrong`.
5. `src/design-system/Field.tsx`: single-line and multiline text input on `surface`, `ash` placeholder, `focus` 2 px ring on focus (colour change only, animated with `ease.out` over `duration.micro`), label above in `label` variant, error text below in `caption`.
6. `src/design-system/Surface.tsx`: a view on `surface` with `radius.lg`, padding from `space`.
7. `src/design-system/motionPreference.ts`: `useMotionPreference()` returns `{ reduced: boolean }` from Reanimated's `useReducedMotion()`; a pure `pickMotion(reduced, spatial)` returns either the spatial spring config or `{ kind: 'fade', ms: tokens.motion.reducedMotion.fadeMs }`.
8. `app.json`: `ios.infoPlist.CADisableMinimumFrameDurationOnPhone: true` (120 fps on ProMotion).
9. Update `TodayPlaceholder` to use `Text` and `words` (no visual change beyond the new type).

**Tests** (Jest + RNTL; mock Reanimated with its official Jest setup and expo-haptics with `jest.mock`):
- `Text`: each variant renders with the token font family and size; display variants have the header role.
- `Button`: `onPress` is called once per tap; disabled does not call it and exposes `disabled` state; `haptic="impactLight"` calls `Haptics.impactAsync` with the light style on press-in; no haptic call without the prop.
- `Field`: label is associated (accessible label equals the label text); error text renders when given.
- `pickMotion(false, spring.press)` returns the spring; `pickMotion(true, …)` returns the fade with `fadeMs` 180.

**Acceptance.** Mobile typecheck, tests, lint, boundaries pass; `npx expo-doctor` has no new failures; no colour, size, spacing or motion literal in `src/design-system` (reviewer checks the diff); fonts render in the Design Lab recording (T-003d).

## T-003c · Signature motion components (P2 set) · needs T-003b

**Goal.** Four of DESIGN §3's signature transitions exist as tested components: Title Card, Text Morph, Dissolve, Grain and Breath.

**Do.** In `src/design-system/motion/`, each component with a pure planning function next to it (planning functions hold all timing maths and are what the tests pin):
1. `TitleCard.tsx` + `titleCardPlan.ts`: props `lines: string[]`, `variant` (`display64 | display48 | display34 | question`), `play` (boolean), `onDone?`. Each line sits in a clipping view; each word rises from `translateY: 100%` to 0 and opacity 0 → 1 with `ease.out` over `duration.title`, word delays `stagger.word` apart, continuing across lines. `titleCardPlan(lines)` returns `[{ line, word, delayMs, durationMs }]` and `totalMs`. Reduced motion: the whole card fades in over `reducedMotion.fadeMs`, no translation.
2. `TextMorph.tsx` + `textMorphPlan.ts`: props `text`, `variant`. When `text` changes, characters common to the old and new strings at the same position stay; removed characters slide up 30% and fade out, added characters slide in from 30% below and fade in, each `stagger.char` apart, on `spring.press`. `textMorphPlan(from, to)` returns `{ keep: number[], exit: number[], enter: number[], delays }` with a deterministic diff (longest common prefix and suffix; the middle is exit + enter). Reduced motion: crossfade the whole text over `reducedMotion.fadeMs`. The accessible label is always the new text.
3. `Dissolve.tsx`: props `source` (expo-image source), `recyclingKey`. Cross-dissolves from the previous source over `duration.dissolve` with `ease.dissolve`, blurring the outgoing image by `texture.crossfadeBlurPx` (expo-image `transition` for the fade; Skia or expo-image blur for the outgoing layer, whichever works on SDK 57 without dropping frames; name the choice under Decisions). Reduced motion: plain crossfade, no blur.
4. `GrainBreath.tsx` + `grainShader.ts`: wraps children (a hero image or video). Ken Burns scale `texture.kenBurns.from → to` over `texture.kenBurns.ms`, reversing (`withRepeat`, reverse) on `ease.inOut`; a Skia `RuntimeEffect` film-grain overlay at `texture.grainOpacity` whose seed advances at `texture.grainFps`. Reduced motion: no scale animation and a static grain frame. `pointerEvents="none"` on the overlay; the shader source is a string constant with a unit test that it compiles with `Skia.RuntimeEffect.Make` when Skia's Jest mock allows it, otherwise that test is UNVERIFIED and says why.

**Tests.**
- `titleCardPlan`: two lines "The Week" / "It Rained" → 4 words with delays 0, 60, 120, 180 and `totalMs` 180 + 900.
- `textMorphPlan('Hold to answer', 'Recording')` and `('Recording', 'Saved')`: exact keep/exit/enter sets; `('Saved', 'Saved')` → no exit or enter.
- Each component renders with reduced motion on (mock `useReducedMotion` → true) and exposes the final text or image immediately to accessibility (TitleCard: all lines readable; TextMorph: the new text).
- `GrainBreath` renders children and an overlay with `pointerEvents="none"`.

**Acceptance.** Mobile typecheck, tests, lint, boundaries pass; no motion literal outside `packages/design`; components appear in the Design Lab (T-003d).
