## Preamble

**Goal of P1.** A monorepo that installs, typechecks, lints, checks boundaries, tests, builds and runs CI, with the six workspaces from ARCHITECTURE §2 in place and empty of product features. Every later task builds on it, so correctness and exact commands matter more than speed.

**Read first:** `CLAUDE.md` (all 15 rules), `docs/architecture/ARCHITECTURE.md` §1, §2, §7, §9, `docs/decisions/DECISIONS.md` D6, D8, D18, D25.

**Versions (D25, checked 2026-09-26).** Node 22 (`.nvmrc` contains `22`), pnpm `10.33.0` (root `packageManager`), TypeScript `~6.0.3`, Vitest `~4.1.11`, Zod `^4.6.5`, Hono `^4.13.9`, wrangler `^4.141.0`, `@cloudflare/vitest-pool-workers` `^0.22.0`, typescript-eslint `^8.70.1`, eslint 9, prettier 3, dependency-cruiser `^18.4.0`, Expo SDK 57 (`expo` `~57.0.25`, `jest-expo` `~57.0.5`, `expo-router` `~57.0.23`, `react-native` as `npx expo install` chooses). Never use TypeScript 7 or Vitest 5 (D25 says why).

**Package names.** `@life/contracts`, `@life/story`, `@life/design`, `@life/render`, `@life/api`, `@life/mobile`. All `private: true`, `"type": "module"` except `@life/mobile` (Expo default).

## T-001a · Workspace, tooling and the three pure packages

**Goal.** `pnpm install && pnpm typecheck && pnpm lint && pnpm test` pass at the root with `packages/contracts`, `packages/story` and `packages/design` in place.

**Do.**
1. Root `package.json`: `"name": "life-documentary"`, `private`, `packageManager: "pnpm@10.33.0"`, `engines.node: ">=22 <23"`, scripts:
   - `typecheck`: `pnpm -r --if-present typecheck`
   - `lint`: `eslint .`
   - `format`: `prettier --write .` and `format:check`: `prettier --check .`
   - `test`: `pnpm -r --if-present test`
   - `build`: `pnpm -r --if-present build`
2. `pnpm-workspace.yaml` with `packages: ['apps/*', 'packages/*']`. `.npmrc` with `node-linker=hoisted` (D25). `.nvmrc` with `22`.
3. `tsconfig.base.json`: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `forceConsistentCasingInFileNames`, `skipLibCheck`, `isolatedModules`, `verbatimModuleSyntax`, `module`/`moduleResolution` `"Bundler"`, `target` `"ES2022"`, `resolveJsonModule`.
4. ESLint 9 flat config (`eslint.config.js`) with `typescript-eslint` recommended-type-checked for `packages/**` and `apps/api/**` (type-aware via `projectService`), recommended (not type-checked) for `apps/mobile/**` for now; rules: `@typescript-eslint/no-explicit-any: error`, `@typescript-eslint/consistent-type-imports: error`, `no-console: ["error", { allow: ["warn", "error"] }]`. Ignore `**/dist`, `**/.expo`, `**/node_modules`, `**/out`, `**/.wrangler`, `apps/mobile/android`, `apps/mobile/ios`. `eslint-config-prettier` last.
5. Prettier 3: `.prettierrc.json` `{ "singleQuote": true, "semi": true, "trailingComma": "all", "printWidth": 100 }`; `.prettierignore` mirrors the ESLint ignores plus `pnpm-lock.yaml`.
6. `.editorconfig` (2 spaces, LF, final newline). `.gitignore`: `node_modules`, `dist`, `out`, `.expo`, `.wrangler`, `*.log`, `.env*`, `apps/mobile/ios`, `apps/mobile/android`, `coverage`, `.DS_Store`.
7. `packages/contracts`: depends on `zod` only. `src/index.ts` re-exports:
   - `src/version.ts`: `export const CONTRACTS_VERSION = 1 as const;`
   - `src/ids.ts`: `Uuid = z.uuid()` (branded type `Uuid`), `LocalDate = z.string().regex(/^\d{4}-\d{2}-\d{2}$/)` with a refinement that the date exists (reject `2026-02-30`), `IanaTimeZone = z.string().min(1)` with a refinement using `Intl.supportedValuesOf('timeZone')` when available, else `new Intl.DateTimeFormat('en', { timeZone })` not throwing.
   - `src/errors.ts`: `ApiErrorCode = z.enum(['bad_request','unauthorized','forbidden','not_found','conflict','rate_limited','internal'])`, `ApiError = z.object({ error: z.object({ code: ApiErrorCode, message: z.string().min(1) }) })`.
   - `src/health.ts`: `HealthResponse = z.object({ status: z.literal('ok'), service: z.literal('life-api'), contractsVersion: z.literal(1), build: z.string().min(1) })`.
   Scripts `typecheck` (`tsc -p tsconfig.json --noEmit`), `test` (`vitest run`). Exports via `"exports": { ".": "./src/index.ts" }` (source exports; no build step for pure packages).
8. `packages/story`: depends on `@life/contracts` (`workspace:*`) only. `src/index.ts` exports `STORY_ENGINE_VERSION = 1 as const` and nothing else yet. Same scripts.
9. `packages/design`: no dependencies. `src/tokens.ts` exports a `tokens` object typed `as const`:
   - `color`: `theatreBlack '#0A0A0C'`, `velvet '#1A1418'`, `screenWhite '#F4F1EC'`, `filmAmber '#E0A458'`, `projectorCyan '#7FD1E6'` (VISION §10), plus semantic aliases `background` → theatreBlack, `surface` → velvet, `text` → screenWhite, `accent` → filmAmber, `focus` → projectorCyan.
   - `space`: `[0, 4, 8, 12, 16, 24, 32, 48, 64]`; `radius`: `{ sm: 6, md: 12, lg: 20 }`; `font.size`: `{ caption: 13, body: 16, title: 22, display: 34 }`; `motion.durationMs`: `{ fast: 150, base: 250, slow: 450 }`.
   Also `src/contrast.ts` with `contrastRatio(hexA, hexB): number` per WCAG 2.x relative luminance. Same scripts.

**Tests.**
- `packages/contracts/test/ids.test.ts`: `Uuid` accepts a v4 and a v7 UUID, rejects `'abc'`; `LocalDate` accepts `2026-02-28` and `2024-02-29`, rejects `2026-02-30`, `2026-13-01`, `26-01-01`; `IanaTimeZone` accepts `Europe/Dublin`, `Asia/Manila`, rejects `Mars/Olympus`.
- `packages/contracts/test/errors-health.test.ts`: `ApiError` accepts a valid envelope and rejects an unknown code; `HealthResponse` accepts `{ status: 'ok', service: 'life-api', contractsVersion: 1, build: 'dev' }` and rejects `contractsVersion: 2`.
- `packages/design/test/contrast.test.ts`: `contrastRatio('#000000', '#FFFFFF')` ≈ 21 (to 2 decimals); `contrastRatio(x, x)` = 1; `text` on `background` ≥ 7; `accent` on `background` ≥ 4.5; `focus` on `background` ≥ 3.
- `packages/story/test/version.test.ts`: `STORY_ENGINE_VERSION === 1`.

**Acceptance.**
- A clean clone runs `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test` with zero errors.
- `packages/story` has no dependency other than `@life/contracts`; `packages/contracts` none other than `zod`; `packages/design` none.
- No `any`, no `@ts-ignore`, no `eslint-disable` lines.

**Out of scope.** Apps, CI, dependency-cruiser (T-001d).

## T-001b · API skeleton on Workers · needs T-001a

**Goal.** `apps/api` is a Hono app on Cloudflare Workers with a typed health route, a typed error envelope, and tests running inside the Workers runtime.

**Do.**
1. `apps/api/package.json` (`@life/api`): dependencies `hono`, `@life/contracts`; devDependencies `wrangler`, `vitest` (`~4.1.11`), `@cloudflare/vitest-pool-workers`, `@cloudflare/workers-types` or the types from `wrangler types` (choose the one the current Cloudflare docs recommend for the pinned wrangler; name it under Decisions). Scripts: `dev` (`wrangler dev`), `typecheck` (`tsc --noEmit`), `test` (`vitest run`), `deploy:dry` (`wrangler deploy --dry-run --outdir dist`), `build` (same as `deploy:dry`).
2. `apps/api/wrangler.jsonc`: `name: "life-api"`, `main: "src/index.ts"`, a `compatibility_date` of `2026-09-01`, `compatibility_flags: ["nodejs_compat"]`, `vars: { BUILD: "dev" }`, bindings declared but pointing at placeholders that do not need to exist for `--dry-run`: D1 `DB` (`database_name: "life-db"`, `database_id: "00000000-0000-0000-0000-000000000000"`), R2 `MEDIA` (`bucket_name: "life-media"`). No queues or workflows yet.
3. Layer folders from ARCHITECTURE §2 with an `index.ts` each exporting nothing yet except where below: `src/routes/`, `src/auth/`, `src/data/`, `src/pipeline/`, `src/providers/`, `src/policy/`, `src/shared/`.
4. `src/shared/env.ts`: `type Env = { DB: D1Database; MEDIA: R2Bucket; BUILD: string }`.
5. `src/shared/errors.ts`: `apiError(c, status, code, message)` returning JSON that satisfies `ApiError` from `@life/contracts`.
6. `src/routes/health.ts`: `GET /health` → `200` with a body built as `HealthResponse.parse({ status: 'ok', service: 'life-api', contractsVersion: CONTRACTS_VERSION, build: env.BUILD })`.
7. `src/index.ts`: `new Hono<{ Bindings: Env }>()`, mounts health, `notFound` → `404` `not_found`, `onError` → `500` `internal` with message `"Something went wrong."` (never the error text), and logs the error with `console.error`.

**Tests** (`apps/api/test/*.test.ts`, run in the Workers pool with `SELF.fetch` or `app.request` with the test env):
- `GET /health` → 200; body parses with `HealthResponse`; `build` equals the test env's `BUILD`.
- `GET /nope` → 404; body parses with `ApiError`; `code === 'not_found'`.
- A route that throws (registered only inside the test on a fresh app built by an exported `createApp()` factory) → 500 with `code === 'internal'` and a message that does not contain the thrown text.

**Acceptance.**
- `pnpm --filter @life/api typecheck`, `test`, `deploy:dry` pass; `dist/` is not committed.
- No vendor SDK imported anywhere; no secrets.
- `createApp()` is exported from `src/app.ts` and `src/index.ts` exports `default createApp()` (so tests build their own app).

**Out of scope.** D1 tables, R2 calls, auth, other routes.

## T-001d · Boundaries, CI and README · needs T-001b, T-001c

**Goal.** Import boundaries and the no-biometrics rule are enforced by one root command, and CI runs every check on every PR and on `main`.

**Do.**
1. `tooling/dependency-cruiser.cjs` and root script `boundaries`: `depcruise apps packages --config tooling/dependency-cruiser.cjs`. Forbidden rules (each with a clear `comment`):
   - `packages/contracts` may import only `zod`.
   - `packages/story` may import only `packages/contracts` and `zod`.
   - `packages/design` imports nothing outside itself.
   - `packages/*` never import `apps/*`.
   - `apps/mobile/src/features` never imports `apps/mobile/src/data` or `apps/mobile/src/services`.
   - nothing imports `apps/mobile/app` (the routes folder).
   - `apps/mobile` outside `src/data` never imports `expo-sqlite`, `drizzle-orm` or `better-sqlite3`.
   - `apps/api/src` outside `src/providers` never imports `@anthropic-ai/sdk`, `elevenlabs`, `@elevenlabs/*`, `@remotion/lambda`, `openai`.
   - no-biometrics: no module anywhere whose path matches `face-api|@vladmandic/face|face-detector|expo-face-detector|react-native-vision-camera-face|@mediapipe/tasks-vision|mlkit.*face|face-recognition|voiceprint|speaker-id|pyannote`.
   - no circular dependencies.
2. `tooling/scripts/check-banned-identifiers.mjs` and root script `banned`: scans `apps/**/src`, `apps/mobile/app`, `packages/**/src` (not tests, not `node_modules`) for the case-insensitive identifiers `faceDetect`, `FaceDetector`, `faceEmbedding`, `speakerId`, `voiceprint`, `detectFaces`; exits 1 listing file:line when found. Add a Vitest test in `tooling/test/check-banned.test.ts` that runs the scanner's exported function on a temporary folder with and without an offending file (behaviour, not the repo's own text). Root script `boundaries` runs depcruise and then `banned`.
3. `.github/workflows/ci.yml`: triggers `pull_request` and `push` to `main`; one job `checks` on `ubuntu-latest`, `concurrency` per ref with cancel-in-progress; steps: checkout, `pnpm/action-setup` (version from `packageManager`), `actions/setup-node` with `node-version-file: .nvmrc` and pnpm cache, `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm boundaries`, `pnpm test`, `pnpm --filter @life/api deploy:dry`. Timeout 20 minutes. No secrets.
4. `README.md`: one paragraph on the product (link `docs/VISION.md`), prerequisites (Node 22, pnpm 10), the commands with one line each, the workspace list, where docs and tasks live.
5. `CLAUDE.md` "Commands" section: replace the placeholder lines with the verified commands (this section only).

**Tests.** `tooling/test/check-banned.test.ts` as above. `tooling/` is not a workspace: add `vitest` as a root devDependency, a root `vitest.config.ts` whose `include` is only `tooling/test/**/*.test.ts`, and change the root `test` script to `pnpm -r --if-present test && vitest run`. A deliberate violation check, done locally and reported (not committed): temporarily import `apps/mobile/src/data` from `src/features/today` and show `pnpm boundaries` fails, then revert.

**Acceptance.**
- `pnpm boundaries` passes on the clean repo and fails on each deliberate violation you tried (report which).
- CI is green on the PR with every step listed above.
- README commands are exactly the ones that work.

**Out of scope.** Render job (T-002b adds it), deploy to Cloudflare, EAS.
